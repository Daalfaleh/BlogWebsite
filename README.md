# Blog Website

A PHP and MySQL blogging application with account registration, authentication, post creation, user profiles, and a contact form.

## Stack

- PHP with MySQLi prepared statements
- MySQL/MariaDB
- HTML, CSS, and JavaScript

## Setup

1. Create a MySQL database and import `schosyal_main.sql`.
2. Update the database settings in `config/`.
3. Serve the repository from a PHP-capable web server.
4. Open `index.php` in the browser.

## Main areas

- `includes/` — authentication, signup, post, user, and contact handlers
- `assets/`, `css/`, `js/` — frontend resources
- `schosyal_main.sql` — starter schema and sample data
